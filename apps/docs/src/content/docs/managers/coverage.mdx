A coverage request means a desk will be empty unless a person procures Allied.

Act on a request for any house you can build for. An SM builds their own house; an RSM,
HM, BA (Building Administrator) or Administrator builds any house. Anyone with that
permission may act, not only the manager paged.

<Callout label="The one rule" critical>
  **An open request never clears itself.** When its window passes unclosed it goes
  overdue and stays visible until a human records what happened.

  Acknowledging is not closing. Acknowledge and walk away and it still goes overdue, into
  the coverage report as a missed-coverage incident.
</Callout>

## Do it

<Steps>
  <li>Open the alert from the banner.</li>
  <li>
    Select <UI>I am handling this</UI>, so the ladder stops paging your colleagues.
  </li>
  <li>Call Allied, or find internal coverage.</li>
  <li>
    Come back and <UI>Close out</UI> with one of four outcomes.
    <span class="step-note">The step people skip, and the only one that ends it.</span>
  </li>
</Steps>

<Table>

| Outcome | Choose it when |
| --- | --- |
| Allied secured | Allied is booked for the window. |
| Covered internally | A worker picked it up, or you assigned one. |
| Desk went unstaffed | Nobody covered it. Needs a written note, and counts as an incident. |
| No longer needed | The block was voided, or the desk regained a worker. |

</Table>

## What you'll see

A closed request leaves the active view. Only **No longer needed** ever closes itself.

One request covers one uncovered stretch at one house. The chain fires per 30-minute
block, so adjacent blocks merge rather than page you eight times for one empty evening.
Merging never re-pages.

## Rules that apply

- **An unanswered request climbs three rungs, an hour apart**, so it always reaches
  somebody. The rungs are the house's RSM, then its HM, then the Housing Manager on duty.
  The holder is re-paged every 15 minutes, never fanned out wider. See
  [Roles and the duty hierarchy](/system/roles).
- **Securing Allied does not re-open the seats.** An otherwise empty desk locks two hours
  before its block starts and stays locked, so nobody piles onto a window already paid for.
  See [How a shift gets covered](/system/coverage-ladder).
- **One worker on the desk is not a coverage failure.** The chain fires only for a block
  with nobody present, so empty seats on a staffed desk stay claimable. See
  [Floating: overview](/system/floating).

## If it goes wrong

<Callout label="The coverage status will not load">
  Silence on this alert means every desk is accounted for, so a failed read is never shown
  as an all-clear. Treat it as unknown coverage and check the house schedule.
</Callout>

**A request you closed came back.** It did not. A new uncovered stretch at the same house
opens its own request. Read the coverage window on the card.
