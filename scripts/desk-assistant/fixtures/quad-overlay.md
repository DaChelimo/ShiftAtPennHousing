# Perimeter doors

Quad courtyard gates are managed by the house office. During posted hours residents badge in
at the main gate. Outside posted hours, do not open a courtyard gate for anyone from the desk;
direct them to the main entrance and escalate to the manager on duty if needed.

# Spare key retrieval

Quad spare keys are held per building in the desk key box. Issue a spare key only to a
resident verified against the roster, log the building, key number, and time, and require
same shift return. Never issue a key to a guest.
