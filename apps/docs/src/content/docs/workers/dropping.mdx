Dropping hands a shift back to your house for this week, whole or part.

## Do it

<Steps>
  <li>Open <UI>My Shifts</UI> and tap the shift.</li>
  <li>
    Choose <UI>Drop the shift</UI>.
    <span class="step-note">
      <a href="/workers/swapping">
        <UI>Swap it</UI>
      </a>{' '}
      trades it instead.
    </span>
  </li>
  <li>
    Leave the scope on <UI>This week only</UI>.
    <span class="step-note">
      <UI>Permanent</UI> covers every remaining week:{' '}
      <a href="/workers/dropping-permanently">Dropping every week</a>.
    </span>
  </li>
  <li>
    Set <UI>How much</UI> to keep part of it.
    <span class="step-note">
      <UI>From now</UI> drops the rest of a running shift.
    </span>
  </li>
  <li>Tap the red button.</li>
</Steps>

## What you'll see

The card reads **Dropping this shift** until the server answers; it is yours until then.

It then moves to <UI>Open Shifts</UI>, and everyone who could claim it hears.

## Rules that apply

- **Drops move in 30 minute steps.** The block is the smallest unit, so there is no half
  block to hand back. See [Core concepts](/system/concepts).
- **<UI>From now</UI> rounds back.** Leave at 17:51 and the gap opens at 17:30, so those 21
  minutes are not credited. See [Hours, caps, and attribution](/system/hours-rules).
- **Any shift can go, even one starting in 20 minutes.** You get a warning, because a gap
  that close means paid cover. See [How a shift gets covered](/system/coverage-ladder).
- **Cover is chased only when the desk would be empty.** One worker still on counts as
  covered, so your seat waits in the feed. See
  [How a shift gets covered](/system/coverage-ladder).
- **There is no reclaim button.** A seat has one owner, so you
  [claim it back](/workers/picking-up) like anyone else. See
  [Core concepts](/system/concepts).

## If it goes wrong

**You cannot claim it back.** Somebody else took it, or the desk locked. An otherwise empty
desk locks two hours before its block starts, and stays locked once cover arrives.

**Refused as not yours.** A swap or a manager moved it first.
