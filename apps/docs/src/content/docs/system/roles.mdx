Seven roles run this system. Each fixes what you may change, and at which houses.

## How it works

<Table>

| Role                         | Works a desk | Authority                             |
| ---------------------------- | ------------ | ------------------------------------- |
| Student Worker               | Yes          | Their own shifts.                     |
| Student Manager (SM)         | Yes          | Builds and overrides, own house only. |
| Residential Services Manager | Yes          | An HM's powers, minus duty rotation.  |
| Housing Manager (HM)         | Yes          | Full administration of their house.   |
| Building Manager             | No           | The same administration.              |
| Housing Manager on Duty      | Varies       | An HM's authority, at all 13 houses.  |
| Administrator                | No           | Every power above, at all 13 houses.  |

</Table>

Schedule authority travels; people authority does not. HM, Building Manager, RSM and
Administrator build and override any house's week, because an empty desk is a campus
problem. Hiring, role grants and leave stay own-house: staffing a house is that house's
call.

Four roles are never floated and never broadcast to: HM, Building Manager, RSM and
Administrator. Both mechanisms target students, so an SM floats like any worker.

Manager hours are Monday to Friday, 08:00 to 17:00. Outside them one Housing Manager on
Duty holds HM authority everywhere, handing over each Friday at 08:00. Only HMs and
Building Managers take that rotor.

## Why it works this way

One named person holds all 13 houses off hours, because a duty split across many managers
is a duty nobody answers.

Handover lands Friday 08:00, not Monday, so the weekend opens a duty week rather than
splitting one.

## What this means for you

An SM acting on another house is refused. An off-hours problem reaches the duty manager,
not your own house's.
