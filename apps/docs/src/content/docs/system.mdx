Floating, escalation, and hours attribution are not features of one screen. A worker meets
floating as a notification, a manager meets it as a name in their grid, and IT meets it as
an algorithm. This section is the one explanation all three link into.

If you are reading the whole site, read this section first. The worker and manager sections
tell you **what you do**; these pages tell you **why it did that**.
