A permanent drop gives up a recurring slot for the rest of the current term or season,
not forever.

## Do it

<Steps>
  <li>Open <UI>My Shifts</UI> and tap any copy of the slot.</li>
  <li>
    Choose <UI>Drop the shift</UI>, then switch the scope to <UI>Permanent</UI>.
  </li>
  <li>Set <UI>How much</UI> to keep part of the slot.</li>
  <li>
    Read the confirmation summary.
    <span class="step-note">
      It names when your period ends and how many future weeks you give up.
    </span>
  </li>
  <li>Confirm.</li>
</Steps>

## What you'll see

Every future week you still own goes at once. The slot moves to **Permanent openings**,
where another worker can take the whole run. Your updates tab records what you dropped.

## Rules that apply

- **Permanent means the rest of the current term or summer season.** Each period is built
  fresh, so an autumn drop leaves spring untouched. Breaks carry no recurring slot,
  so they are never in scope. See [The operating calendar](/system/calendar).
- **Three kinds of week are skipped**: the shift you are working now, occurrences already
  past this week, and weeks somebody else owns. A seat has one owner, so only weeks still
  yours are dropped. See [Core concepts](/system/concepts).
- **Part of a slot must be one unbroken run.** Drop 22:00 to 24:00 of a 19:00 to 24:00 slot,
  but never a hole in the middle. A slot is one run of 30 minute blocks. See
  [Core concepts](/system/concepts).

## If it goes wrong

**The summary counts fewer weeks than you expected.** Weeks another worker holds are not
yours to give.

**You want the slot back.** Take it from **Permanent openings**, or ask whoever picked it up
for a swap.
